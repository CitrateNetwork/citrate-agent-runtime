# HUP-S2.2: OS sandbox for agent-shell, and the general `shell_run` tool

Planset: citrate-core `.agentile/planset/2026-09-30-hermes-upskill/` (04_FEATURES_BDD US-2.2,
05_SPRINTS_AND_WPS S2.2). Tracking: CitrateNetwork/citrate-federation#279.

## What changed

- `agent-shell/src/sandbox.rs`: the OS sandbox layer. macOS Seatbelt through
  `/usr/bin/sandbox-exec` with a per-run profile (deny by default, no network operation ever
  allowed, writes only in the run's write roots and its scratch HOME, reads limited to those,
  the system set and the toolchain directories; `.git/hooks`, `.git/config` and `.env*` denied
  even inside a grant; every path passed as a `-D` parameter). Linux bubblewrap (`--unshare-all`,
  read-only system binds, writable binds of the grant and the scratch HOME, masks over hooks,
  git config and top-level env files). Detection probes the backend once per process. Modes:
  `Required` (fail closed), `Preferred`, `Off`. Landlock is not implemented; Windows has no
  shell at all (the crate is unix-only).
- `ShellRunner::with_scope`: the cwd check now returns the folders a run may write;
  `ShellRunner::new` keeps the cwd as the only one. `RunPlan` and `RunReport` carry the
  sandbox summary.
- Toolchain templates (`forge_test`, `slither_scan`, `aderyn_scan`, `medusa_fuzz`): run through
  the OS sandbox when one works (`CITRATE_HERMES_SHELL_SANDBOX`, default `preferred`; junk is
  `required`). Run facts now include `sandbox`.
- `agent-sidecar/src/shell_run.rs`: `shell_run`, off by default (`CITRATE_HERMES_SHELL_RUN=1`),
  offered only to sessions opened with folder grants. Exact argv + cwd, bare program name from
  a fixed search path, cwd inside live read and write subtree folder grants (that grant is the
  only writable folder), OS sandbox required, HIC required for every call through
  `GET/POST /sessions/:id/shell/{pending,decide}` with the decision bound to the argv and cwd
  shown, 300 s decision window, grants re-checked after approval, timeout up to 600 s, 32 KiB
  output cap per stream, untrusted output (taints the session), refused in tainted sessions.

## Proof

- `cargo test -p citrate-agent-shell -p agent-sidecar`: 376 passed (baseline 325), 0 failed.
- macOS run proofs (Seatbelt): `agent-shell/tests/sandbox.rs` (network denied with a local
  listener that never sees a connection; writes outside the grant denied; writes in the grant
  and the scratch HOME allowed; reads outside denied; hooks and env files denied), the
  sandboxed toolchain and worker tests, and the live forge and slither runs
  (`cargo test -p agent-sidecar --lib live_ -- --ignored`) with `sandbox.enforced: true`.
- Linux: `bwrap_command` argv shape only. The run proof is asked of the DGX team on #279.
