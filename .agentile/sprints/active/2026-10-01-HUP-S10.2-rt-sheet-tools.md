# HUP-S10.2 (runtime half): grant-checked sheet tools

Planset: citrate-core `.agentile/planset/2026-09-30-hermes-upskill/` (04_FEATURES_BDD US-10.2
AC1 "Read/write xlsx/csv in grants", 02_ARCHITECTURE section 5 "office / media, in-sidecar").
Core half (Google Sheets + Calendar, Hermes schedule, media): citrate-core branch
`hup/n4-media-sheets`, `.agentile/sprints/active/sprint-hup-s10-everyday/WP-S10.1-S10.2-EVIDENCE.md`.
Base: `hup/n4-grants-e2e` (sessions with grant documents). Federation sprint issue #287.

## What shipped

- `agent-office` (new crate): CSV/XLSX formats over bytes inside `Limits` (see its README).
- `agent-sidecar/src/sheets.rs` (new): `sheet_read {path, sheet?}` and
  `sheet_write {path, rows, sheet?}`, host `sidecar`. Offered only to sessions opened with a grant
  document, next to the file tools; the names are reserved there. Every path goes through
  `SessionGrants::check` at use: read and write separate, deny list first, full-access reads come
  back `Untrusted` (taint), writes need a live write folder grant, never follow a leaf symlink,
  refuse multi-link files, never create folders. A write is built and limit-checked in memory
  before the file is opened, so a refused write leaves the file as it was.
- `sessions.rs`: reserve the names, add the specs, route the calls (three small hunks).
- `grants.rs`: `open_nofollow` / `hard_linked` made `pub(crate)` for reuse.

## Tests

- `agent-office`: 3 unit + 19 integration (round trips, formula neutralising, limits, inflate
  bomb refused before parsing, positions, bad sheet names, non-UTF-8, non-finite numbers).
- `agent-sidecar` `sheets_session_tests`: 9 (round trip CSV/XLSX in grants, read grant never
  writes, outside and `..` denied, deny list wins under a home grant, symlink and hard link never
  written, full-access reads untrusted and never write, oversized write refused with the file
  untouched, bad arguments, specs, session offering and name reservation).
- Mutation checks (each made a test fail): grant check on read, grant check on write, hard-link
  refusal, untrusted full-access reads, inflate check, CSV neutralising, row/byte limits, NaN,
  column-only truncation flag, leading-row padding.
